# Security policy

## Supported versions

Only the latest published version of `lucaslgt.WorkflowContext` receives fixes.

## Reporting a vulnerability

Do not open a public issue for a security vulnerability.

Report it privately through GitHub instead:
[report a vulnerability](https://github.com/lucaslenglet/WorkflowContext/security/advisories/new).

Reports are read, but as stated in [CONTRIBUTING.md](CONTRIBUTING.md), this repository is maintained by a
single author, and no response, fix or timeline is guaranteed.
